## English

HomeLab Portal's first proposed release brings together device-reported addresses
and Beszel monitoring in a lightweight self-hosted Flask dashboard.

### Included

- SQLite registry, shared-token Heartbeat, separate LAN/ZeroTier addresses,
  last-seen timestamps and IP-change logging.
- Linux/Python and Windows/PowerShell one-shot clients, Linux timer examples.
- Beszel CPU, memory, disk, load, temperature, uptime and status through persistent
  one-to-one device links.
- Full Device Mini Cards and details, live and historical native SVG charts.
- Lite Style with five-second polling and no historical/chart payloads.
- Network tab with status/address summaries, retaining Device selection when switching.
- UI cleanup for wrapping, status colors and missing/invalid data; ES5/XHR frontend.
- Isolated Flask tests, mocked frontend tests and GitHub Actions Smoke tests.
- Bilingual setup, configuration, API, security and acceptance documentation.

### Installation and cadence

Follow the [README](../../README.md). Python 3.12 and Node 22 are CI baselines;
Node is only needed for frontend tests. Configure `.env` with a newly generated
Heartbeat secret and your own Beszel connection. Replace client placeholders.
Linux's example timer reports roughly every five minutes after completion;
browser live polling is every five seconds, Full history refresh every minute.
Windows cadence depends on the task you create.

### Known limitations

- The license has not been selected; approval is required before a licensed
  open-source release. No license is adopted by this draft.
- Full previously displayed successfully on a real iPad mini 1 / iOS 9 Safari.
  Lite, the new Network tab and latest UI changes still need real-device acceptance.
- Network is reported inventory, not scanning, reachability checks or topology discovery.
- Read endpoints expose device information without a Portal login layer. Use a
  trusted network or external access control; plain HTTP is not encrypted.
- Flask's built-in server is supplied, not a hardened public hosting setup.
- Optional Heartbeat fields lack strict schema validation. Beszel integrations
  depend on its available fields/version, and some HTTP failures remain unnormalized.
- Live history resets on reload. Persistent history depends on Beszel; the nominal
  window is a record limit and may cover longer periods if samples are missing.

No real device data or screenshots are included. See the
[release checklist](../release-checklist.md) before creating any tag or Release.
